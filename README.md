## О проекте

**Clicker Game** — это учебный проект, разработанный на Unity, который демонстрирует базовую механику классических кликер-игр. Проект находится на начальном этапе разработки, но уже реализован основной игровой цикл.

> [!NOTE]
> Проект создаётся в образовательных целях для изучения архитектуры Unity и работы с ScriptableObject.

---

## Возможности

| Функция | Описание |
|---------|----------|
| **Клики** | Ручной сбор ресурсов по нажатию на объект |
| **Автоклики** | Пассивный доход с заданным интервалом |
| **Система магазина** | Покупка улучшений за игровую валюту |
| **ScriptableObject** | Хранение данных предметов (цена, тип, размер, название) |
| **Визуальное отображение** | Интерфейс с актуальной информацией о прогрессе |

---

## Технологии

- **Движок**: Unity 2022.3+  
- **Язык**: C# 11  
- **Архитектура**:  
  - `ScriptableObject` для данных предметов  
  - Компонентный подход Unity
